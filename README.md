## 200M 峰值、3M 固定、15M/50M，这三种带宽不能直接比大小

阿里云轻量全系标 200Mbps 峰值带宽、不限流量，但这个 200M 是峰值共享，不是独享承诺，高峰时段会有波动，所以不能按"一直跑 200M"来规划容量。腾讯云的主流特价档走另一套口径：3M、5M、6M 固定带宽，配 300GB、500GB、600GB 的月流量包，用超了要另外算。雨云给的是上行和下行分开标，国内 2核2G 是 15M 上行、50M 下行，不限流量。

换算一下就有体感了。1Mbps 带宽的理论下载速度约 128KB/s，3Mbps 约 384KB/s，打开一张 300KB 的图片要接近 0.8 秒。50M 下行理论约 6.4MB/s，但国内节点是否为独享带宽，公开页没有写明，按满速规划是不稳的。

三种口径对应的场景也不一样：

- 博客、企业展示站、JSON 接口为主的小程序后端：3M 就够，流量包 300GB/月 折合日均 10GB 出流量，正常访问量很难用满。
- 要传图、发文件、做下载或视频封面：看下行带宽和不限流量，阿里云 200M 峰值适合突发，雨云 50M 下行适合持续。
- 直播推流、大文件持续下载、电商秒杀：三种都别选。带宽是共享或有限的，这类业务需要的是独享带宽和弹性伸缩，得转到 ECS/CVM 这类标准云服务器。

## 几个买之前最常问的问题

**3M 带宽够跑小程序后端吗？**

够，前提是接口以 JSON 为主。腾讯云 4核4G3M 档给的 300GB 月流量，折合日均 10GB 出流量，JSON 接口的小程序后端很难用满。3Mbps 约 384KB/s，单次请求返回几十 KB 的话，日常并发没问题。一旦接口要返回图片、音频或大文件，3M 会立刻成为瓶颈，这种场景要么加带宽，要么把静态资源放对象存储。

**2核2G 能不能同时跑 MySQL 和 Redis？**

能装，但很容易出问题。有测评显示阿里云 2核2G 同时跑 Web 服务和 MySQL 时，内存占用轻松突破阈值，触发 OOM 后系统直接杀进程，这台机器的定位是"单应用运行机"。2核4G 才能稳定同跑 Nginx、MySQL、Redis 三件套，也是被公认为"建站最热门机型"的那一档，日均几千访问量可以承载。小程序后端如果要用数据库加缓存，别在 2GB 内存上省这 ¥10/月。

**轻量服务器能不能中途升级配置？**

这点要分厂商看。雨云的配置和带宽支持升降，按天计费，升级几分钟完成。腾讯云的说法在公开资料里存在矛盾，有文章说支持套餐整体升级、控制台一键完成，也有对比表写"不可中途升级，只能换配或重装"，没拿到官方文档原文之前，建议下单前自己在控制台确认。阿里云轻量明确不支持自由升降配，需要弹性扩容应转 ECS。

**38 元档抢不到怎么办？**

腾讯云同配置错过秒杀是 109 元/年（1.4 折，首单限 1 个），阿里云没抢到秒杀可以买 68 元/年的常规新客款，硬件参数和 38 元档一致，库存更稳。如果只是想要一台便宜机器练手，雨云 1核1G 首月 5 折后 ¥9，试错成本比抢秒杀低得多。
